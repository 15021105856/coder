# v7 B5 课次与体重身份契约

产品仍为 v7 / 7.0.0。本契约不修改真实训练数据文件；身份在读取、导入和保存时写入权威快照，而不是改写内嵌数据集。

## 身份

- 字段名 `eid`。课次必须以 `s_` 开头，体重必须以 `w_` 开头，后接 16 位十六进制。
- 作用域是**同一日期**的 `sessions` 或 `weight` 数组。另一天可以出现相同字符串；跨数组前缀不同，不能把课次身份当作体重身份。
- `eid` 不是开始时刻、测量时间、名称、数值或当前下标。相同开始时刻的多条课次、相同测量时间的多条体重各自拥有身份。
- 编辑内容、修改时刻、重排、保存、导出、刷新都不改变已分配的 `eid`。
- 历史无身份数据按 `种类 + 日期 + 同一内容指纹的出现次序 + 去掉 eid 后的规范内容` 计算确定性身份。重复加载同一历史内容得到同一身份，不使用随机数。
- 内容完全相同的历史项靠出现次序区分。内容一旦在**尚未分配身份**时发生变化，不能证明它仍是哪一条，种子合并和并发合并都不会按相似字段自动对上；并发路径视为不同实体或顺序/字段冲突，而不是静默覆盖。
- 已保存的身份再次遇到无身份、但内容指纹完全一致的导入时复用原身份，避免重复实体。指纹不一致则视为新实体。
- 同一数组内重复 `eid`、非法 `eid`（含错误前缀）会使该次数组稳定化失败：不改写原对象，不覆盖权威，导出可带上 `identityIssues`。
- `eid` 以外的未知字段原样保留。现有数据没有名为 `eid` 的业务字段。

## 合并

并发保存（B3 独占锁内）对 `sessions` / `weight` 按身份做三方合并：

- 不同实体的修改都保留。
- 同一实体的不同字段合并。
- 同一字段改成不同值是冲突，不写权威。
- 同一字段改成相同值可以接受。
- 一方删除、另一方修改同一实体是冲突，不复活删除，也不丢弃修改草稿。
- 双方删除则删除。
- 一方新增、另一方修改或删除其他实体时，能合并的部分保留。
- 双方新增不同实体都保留。
- 只比较仍然存在的共同实体的相对顺序。双方把共同实体排成不同顺序才是顺序冲突。仅有一方调整顺序时采用该顺序。
- 修改开始时刻或测量时间不改变身份，可与另一实体的修改合并。

冲突时沿用 B3：不写权威，保留本页草稿，提示不得说已保存，并可导出。

种子更新使用同一身份规则，但字段冲突时保留本地值，不弹并发冲突。这是文件种子与缓存的旧三方语义，不是两个页面的并发语义。

主动导入仍表示调用方提供该日完整的 `sessions` 或 `weight` 列表（空数组表示清空）。无身份项只有在内容指纹与现有项完全一致时才复用身份。导入不是并发三方合并。
