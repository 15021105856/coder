# v7 B4 输入与动态渲染契约

产品版本 v7 / 7.0.0 与导出格式版本分别管理。当前 JSON 导出使用 `version: 2`、`schemaVersion: 2`、`appVersion: "v7.0"`。历史没有版本、数字格式 1/2、数组、单条记录以及 data/records 信封仍可主动合并；既有 `_meta.schema_version` 中文 32 字段说明不是导出格式版本。

文件与粘贴共用同一文本解析及导入函数：UTF-8 原始文本最大 8 MiB，可接受 JSON 代码围栏，字段和补充数据/基线先完整校验及派生，再修改内存并提交。未来或无效导出格式、不同版本标记、data/records 内容不一致、权威存储快照均拒绝，保持权威和页面数据不变。非法数值、对象混入文本/数字、补充结构异常拒绝；无效日期行仍按原契约跳过并提示。普通扩展字段保留，不能往返的非有限 JSON 数字及超过 64 层的嵌套拒绝。

表单仍用 B2 无损编辑及陈旧基底检查，最终进入相同记录校验后保存；最终记录 JSON 也按 UTF-8 字节计算，最大 8 MiB。文件、粘贴及表单的失败不宣称已保存，保留可恢复的内容。粘贴的补充信息和基线与文件一样处理，失败不清空粘贴框。

营养范围是可选字段：缺失或 null 表示未估算，热量与蛋白分别判断；监测卡、档案和 DOCX 来源说明不得依赖两个范围同时存在。存在时须是顺序合法的有限数字对。

用户数据中的文本按文本显示。监测卡的普通副标题统一转义，只有内部生成的热量范围使用 HTML；睡眠时刻、体重时间等不能成为标签或事件。所有已有字符串型记录、逐课信息、备注、表格和图表提示分别核查；档案体重提示也转义时间。共享图表的 aria、刻度格式和参考标记文本转义。

本批是合并导入，不是完整备份恢复；显式清空/删除状态、巨量备份恢复与 session/weight 稳定身份仍属 B5/B6。新权威键、Web Locks 和 B1–B3 故障恢复规则继续使用。本批不改训练算法、真实数据或产品版本，不宣布跨平台验收。
