# v7 / B2 单日编辑契约

本批在 B1-R4 之后完成 R03，应用、数据格式和文件名继续使用 v7。

- 表单载入时保存整条记录及各控件实际显示的字符串。保存只修改显示值发生变化的字段；未修改的文字感受、训练类型、鞋款、文本空白和扩展字段保持原值。
- 历史下拉框值不在预设选项内时，以安全文本节点加入一个原值选项。原文字感受只有用户主动选择数字感受时才变成数字。
- 原有 32 个标准字段仍做既定归一化；普通 JSON 扩展字段保留。`__proto__`、`constructor`、`prototype` 顶层键排除。真实数据集保持原样。
- 保存前，将页面内当前目标记录与载入基底逐值核对。导入、粘贴、删除或新增同日记录造成差异时，拒绝写入，保留草稿，显示「放弃草稿并重载本日」。重载是用户明确放弃旧草稿的动作，不自动丢弃草稿。
- 不相关日期的导入不阻止当前日期编辑。数值非法时拒绝写入并保留原输入；用户主动清空字段时写入空值。
- 保存失败或结果未知仍使用 B1 的内存与导出路径。再次提交同一份草稿可以重试；没有改动且无待保存状态时不重复写入。
- B2 的陈旧检查覆盖同一页面内的数据变更。跨页面串行化、同日并发冲突和旧 HTML 版本保护属于 B3，不能据 B2 通过宣称已实现。
- 删除记录与「恢复预填数据」的完整语义、全部导入版本及渲染边界、课次身份、完整备份恢复分别交由后续批次验证。
