# 个人训练监测系统 v7 · B5 身份与合并

日期：2026-10-09。基线：已交付的 B4 源码。产品仍为 v7 / 7.0.0、离线单 HTML。以下是本轮实现者结果，不是独立审计结论。

## 身份

课次和体重使用字段 `eid`。课次是 `s_` 加 16 位十六进制，体重是 `w_`。作用域是同一天的对应数组。身份不由开始时刻、测量时间、名称、数值或下标决定。历史无身份数据按日期、种类、相同内容的出现次序和去掉 `eid` 后的规范内容做确定性分配，重复加载不变。内容指纹完全一致的再次导入复用原身份。重复或非法身份不改写权威。未知字段保留。真实数据集文件没有被改写。

并发保存按身份做三方合并，沿用 B3 的独占锁。冲突不写权威，草稿可导出。种子更新在字段冲突时保留本地，不使用并发冲突提示。带完整列表的主动导入仍替换该数组；无身份且内容指纹一致时复用身份。

契约：`docs/identity-contract-v7-b5.md`。
